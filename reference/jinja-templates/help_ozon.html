OZ Как подключить Ozon

Нужны два ключа: основной — Seller API (заказы, начисления, остатки, товары) и, по желанию, ключ рекламы — Performance API (кампании и ДРР). Оба дают только чтение данных.

1. Ключ Seller API — роль «Admin read only»

{{ key_steps('ozon') }}
Почему именно «Admin read only»

Эта роль видит все разделы кабинета, но ничего не может изменить. Ключи с другими ролями не подходят: например, ключ «Товары» не видит заказы и финансы — сервис скажет, к каким разделам не хватает доступа.

Срок действия ключа

Ozon ограничивает срок действия ключа Seller API (по документации Ozon — 3 месяца). Сервис показывает, сколько дней осталось, на странице «Магазины» — за две недели до конца замените ключ там же, в блоке «Заменить ключи».

2. Ключ рекламы — Performance API (по желанию)

Без него сервис посчитает прибыль по начислениям, но не покажет рекламные кампании, клики и ДРР по каждому товару.

{{ ads_steps('ozon') }}

Ключ рекламы можно добавить и позже: «Магазины» → «Заменить ключи или подключить рекламу».

3. Что будет после подключения

  1. Сервис проверит, что ключ видит заказы, финансы и товары.
  2. Загрузит год истории — обычно несколько минут. Ход загрузки видно на странице «Магазины».
  3. Дальше данные обновляются сами каждые 30 минут, новые заказы — чаще.
  4. Укажите себестоимость (можно файлом Excel) и систему налогообложения — и увидите чистую прибыль.
Как отключить доступ

Удалите ключ в кабинете Ozon (Настройки → Seller API) — доступ закроется сразу. Магазин и его данные в сервисе можно удалить на странице «Магазины».

Названия пунктов меню Ozon иногда меняет. Шаги сверены с документацией Ozon для разработчиков (docs.ozon.ru) в сентябре 2026 года.
