Начните за 3 шага

Никаких установок — только ключ площадки с доступом на чтение.

1

Создайте ключ «только чтение»

В кабинете площадки — по пошаговой инструкции. По такому ключу нельзя ничего изменить.

2

Дождитесь загрузки

Мы проверим, что ключ видит заказы и финансы, и сами загрузим год истории — это несколько минут.

Смотрите и решайте

Укажите себестоимость и налоги (можно файлом Excel) — и видите чистую прибыль. Данные обновляются сами.

Вопросы и ответы

Сколько стоит?

Сервис в разработке и проходит закрытое тестирование. Тарифы появятся перед запуском.

Какие площадки поддерживаются?

{% for m in all_marketplaces() %}{{ m.title }} — {{ 'бета' if m.beta else 'работает' if m.ready else 'скоро' }}{{ '; ' if not loop.last else '.' }}{% endfor %} В одном аккаунте можно держать несколько магазинов разных площадок.

Может ли сервис что-то изменить в моём кабинете?

Нет. Мы просим ключ с доступом только на чтение: по нему площадка не даёт менять цены, карточки, остатки или рекламу.

Откуда берутся цифры и насколько они точные?

Из API площадки: заказы, начисления, остатки, реклама. Прибыль считается по начислениям — тем же строкам, что в финансовых отчётах кабинета. Пока начислений по свежему заказу нет, прибыль показана как оценка со значком «≈». Подробнее — в разделе «Что значат цифры».

Сколько истории загружается?

При подключении — год (сколько отдаёт площадка), дальше данные обновляются каждые 30 минут, новые заказы — чаще.

Можно дать доступ бухгалтеру или менеджеру?

Да: добавьте сотрудника с ролью «только просмотр» или «администратор» и выберите, какие магазины он видит.
