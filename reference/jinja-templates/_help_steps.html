{# Шаги «где взять ключ» — одни и те же в мастере подключения и в справке. Сверено с официальной документацией 23.09.2026: docs.ozon.ru/api/seller, docs.ozon.ru/api/performance, dev.wildberries.ru/docs/openapi/api-information, yandex.ru/dev/market/partner-api (concepts/api-key, concepts/access). Площадки иногда переименовывают пункты меню — если пункт не нашёлся, ищите по смыслу. #} {% macro key_steps(code) %} {% if code == 'ozon' %}
  1. Войдите в личный кабинет Ozon Seller (seller.ozon.ru) как владелец или администратор магазина.
  2. Откройте Настройки → Seller API и нажмите «Сгенерировать ключ».
  3. Название — любое, например «seller.bz». Уровень доступа — Admin read only (только чтение). Если Ozon спросит, для чего ключ, — выберите внешний сервис и впишите «seller.bz».
  4. Нажмите «Сгенерировать» и сразу скопируйте ключ: Ozon показывает его только один раз.
  5. Вставьте в форму Client ID (номер кабинета — он указан в том же разделе Seller API) и сам API-ключ.
{% elif code == 'wb' %}
  1. В личном кабинете продавца Wildberries откройте раздел «Интеграции по API».
  2. Нажмите «+ Создать токен» и выберите вкладку «Для интеграции вручную».
  3. Тип токена — «Базовый». Персональный токен по правилам Wildberries нельзя передавать сторонним сервисам.
  4. Название — любое, например «seller.bz». Категории: Контент, Аналитика, Цены и скидки, Маркетплейс, Статистика, Финансы, Продвижение, Поставки, Возвраты (и «Тарифы», если такая категория есть в списке).
  5. Уровень доступа — «Только чтение». Нажмите «Создать», затем «Скопировать и закрыть» — второй раз токен не показывается.
{% elif code == 'yandex' %}
  1. В кабинете продавца Яндекс Маркета нажмите на значок аккаунта → Настройки → в меню слева «API и модули».
  2. В блоке «Токены авторизации» нажмите «Создать новый токен». Создавать токены могут владелец и менеджер кабинета.
  3. Название — любое, например «seller.bz». Доступ — «Просмотр всех данных» (только чтение).
  4. Нажмите «Создать» и скопируйте токен — это Api-Key.
  5. Campaign ID магазина — на той же странице «API и модули», в блоке «Идентификатор кампании».
{% endif %} {% endmacro %} {% macro ads_steps(code) %} {% if code == 'ozon' %}
  1. Откройте кабинет рекламы Ozon — performance.ozon.ru.
  2. Перейдите в Настройки → API-ключи. Если сервисного аккаунта ещё нет — нажмите «Создать новый аккаунт».
  3. Нажмите на название сервисного аккаунта, затем «Добавить новый ключ».
  4. Скопируйте Client ID (вида …@advertising.performance.ozon.ru) и Client Secret в поля «Реклама».
{% endif %} {% endmacro %}
